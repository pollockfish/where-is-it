#### Where Is It?

For the things you know you're going to forget where you put.

Where Is It? is a simple tool for remembering where you put something. Simply send an email to whereisitserver@gmail.com with the subject as the name of the item and the text of the email as its last known location. You can view your list of items via the web UI.
